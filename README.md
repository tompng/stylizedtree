# stylizedtree

もこもこした丸い樹冠の木 (照葉樹・ガジュマル系) を、絵画寄りの見た目で描き、遠景までシームレスに LOD するためのプロトタイプです。three.js (WebGPURenderer) で組んでいて、シェーダー本体は `src/shaders/*.wgsl` に置き、TSL の `wgslFn` で繋いでいます。

```sh
npm install
npm run dev   # WebGPU 対応ブラウザで開く
```

## 表現

- **葉のテクスチャ**: クラスタ表面全体で1枚の葉テクスチャを共有します (`leafAtlas.js` で手続き生成)。球全体の葉の絵を2種類持ち、それぞれの上半球と下半球を、別々の Lambert 正積方位図法の円盤にしています。赤道をまたぐ葉は両方の円盤に描くので、継ぎ目は合います (`leaf_sphere_sample.wgsl`)。UV はフラグメントごとに、クラスタ中心から見た表面の方向で求めます。方向にはクラスタごとのランダムな3D回転をかけるので、2種類の絵でもクラスタごとに違う葉の並びになります。楕円の葉を球面上に一様に散らし、図法の歪みの逆をかけて描くので、球面上で形が保たれます。葉同士は接しないように置きます (大きい葉から順に、置き済みの葉に一定の間隔より近づく候補を捨てる)。接した葉は、ぼかしと閾値で滑らかにつながり、1枚の大きな面に見えてしまうためです。葉はほぼ詰め切った密度で置くので、枚数は葉の大きさで決まります。GUI の `Tree → atlasLeafCount` で目標の枚数から葉の大きさを逆算して作り直し、実際の枚数は HUD に出ます。
- **葉のシェル**: クラスタ (楕円体に数個のこぶを足した形。`clusterShape.js`) の表面を、菱形30面体の30枚の菱形パッチで隙間なく敷き詰めます。近距離では、各パッチを中心まわりに拡大して重ね (overlap)、半径方向に深さをずらし (depth)、縁を反らせます (flare)。反る向きは、外向き・内向き (クラスタ中心側へ丸まる)・パッチごとにどちらかをランダム、から選べます (`flareDirection`)。葉の見かけの大きさは、パッチの拡大率 × こぶによる表面の拡大 × depth による縮小で決まり、パッチごとにばらつきます。`leafSizeCompensation` を有効にすると、パッチごとの拡大率を調整して、このばらつきを打ち消します (拡大率は1倍以上、元の2倍以下に制限。既定で有効)。テクスチャはパッチに貼り付いたまま一緒に動くので、重なったパッチ同士が同じ葉を写すことはありません。パッチの端に近いほど (パッチ内座標 x, y ∈ [0, 1] で 16x(1−x)y(1−y) が小さいほど)、またカメラに対して真横を向いたパッチほど、葉テクスチャの A (葉の中心で 1、輪郭の少し外で 0 になる距離場) に掛ける閾値を上げます (`patchFade`, `grazingFade`)。葉はそれぞれ自分の中心へ縮んで消えるので、パッチの辺で直線に切れることも、広い半透明になることもありません。
- **陰葉っぱ球**: クラスタの内側、シェルの一番深い層 (クラスタ表面の 1 − depth 倍) に、暗く塗る葉の球を置き、シェルの隙間から暗い奥が見えるようにします。テクスチャはシェルと同じ作りで、葉を大きめにした別のアトラスを使います。画面上で球の中心から離れるほど葉を縮めて疎にし、輪郭も球の形も見えないようにします (`inner_fade.wgsl`)。シェルの隙間からしか見えないので、シェルが密なほど (overlap が大きいほど) 効果は弱くなります。GUI の `Look → innerBall` で on/off できます。
- **代理形状の法線**: 陰影はクラスタ形状 (こぶ付き楕円体) の法線を使い、パッチ自身の法線は少しだけ混ぜます。法線は CPU で頂点ごとに焼き、LOD の geomorph では位置と一緒に、粗い段の三角形が補間する値へ寄せるので、切り替えで陰影は変わりません。
- **縁と陰影**: 葉の縁は、ぼかしたカバレッジから作る alpha の傾斜を alpha to coverage に渡し、柔らかく残します。遠くで1ピクセルに複数の葉が入るようになると、mip で平均されたカバレッジはどこも同じくらいの値になり、閾値で切ると層全体が不透明か透明に寄ってしまいます。そこで、葉の幅前後の mip で、平均されたカバレッジに係数を掛けた値へ alpha を切り替えます。係数は、アトラス生成時に作る「閾値を超えるテクセルの割合」の表から、その時点の閾値で求めます。これで、遠くの層も近くで見たときと同じ割合だけ透けます (`farDensity` で倍率を調整)。陰影は ramp の境界を広げ、明暗の幅と、影・AO の濃さを抑えます。GUI の `Look → style` で、以前の硬い見た目 (`crisp`) と切り替えて比べられます。
- **AO**: クラスタ同士の遮蔽を CPU で頂点に焼き (葉と枝)、深い位置にあるパッチほど暗くします。焼いた遮蔽は GUI の `Look → bakedAo` で外して比べられます (深さによる暗さは残ります)。
- **影**: 太陽方向へのクラスタ同士の遮蔽は、球との解析的な交差で頂点ごとに計算します (`st_sunVisibility`)。地面の影も同じ関数をデカールで使い、幹の影はカプセル列で計算します。
- **風**: 幹と枝は高さに応じて揺れます。クラスタは平行移動ではなく、小枝が大枝から分かれる点を支点に、枝ごと風下へ曲がります (bend)。小枝は同じ回転を付け根からの距離の2乗で弱めて受けるので、先端はクラスタの中心についていきます。クラスタ自体も変形し、枝の先の方ほど風下へ流れます (lean)。曲げと lean の強さは、風下へ流れるノイズ (突風) で時間変化します。クラスタの中心から測った位置で決まる変形 (風上の面を押しつぶすなど) は、隣のクラスタと重なった所で面同士が滑り、クラスタが1個ずつの塊に見えるので入れていません。シェルのパッチは中心まわりに一定の角度だけ傾き、法線が風下へ倒れます (patchTilt)。時間変化は、パッチごとの軸で揺らす傾き (flutter) が受け持ちます。どれも回転かパッチ内で線形な動きなので、gridSegments によらず同じ動きになります。陰影の法線も、曲げと傾きに合わせて回します。パッチの傾きは collapse で 0 になり、クラスタの曲げと変形は core の段でも同じ式で続くので、LOD の切り替えで動きは途切れません。
- **その他**: 逆光の透過、空気遠近 (フォグ)。

## LOD

L = log2(referencePixels / 樹冠の投影半径px) とします (referencePixels の既定値は 400)。樹冠の投影半径は、樹冠の横幅の半分を、描画バッファの実ピクセル (devicePixelRatio 込み) で測ったものです。距離が倍になるごとに +1 で、樹冠の半径がちょうど referencePixels になる距離より近いと負になります。すべて連続な変形で繋いでいて、メッシュ構造が変わる切替は、切替前後で同じ見た目に変形し終えた時点でだけ行います。

| L (既定値) | 段 | 中身 |
|---|---|---|
| 1.4 → 3.2 | collapse | パッチの拡大・深さ・反りを 0 にして、隙間なく敷き詰めた状態へ戻す。端と真横での葉の縮小、パッチごとの色のばらつき、深さの暗さもここで消す。アルファ閾値を下げる |
| −1.3 → 3.2 | shell poly | 近づくにつれ、collapse の終わり (3.2) から `gridLevelSpacing` (0.9) ごとに、パッチの格子を1分割、2分割、3分割…と1段ずつ増やす (3.2 で1分割が現れ、2.3 で2分割、1.4 で3分割、0.5 で4分割、−0.4 で5分割。gridSegments で頭打ち)。距離が約半分になるごとに1段増える。遠ざかる向きに見ると、3分割以上から1段減らすときは格子が入れ子にならないので、真ん中の1列と1行を潰す (両側の格子線を粗い段の1本へ寄せ、パッチ座標も一緒に動かす) 形で geomorph し、粗い段と同じメッシュになってから切り替える。2分割から1分割へは、同じパッチ座標の1分割の面の上へ寄せる。最後の段では、1分割の格子を core の三角形の上へ寄せる |
| 3.2 | swap | core の形に重なったパッチ群を、クラスタごとの core に差し替える。core は菱形30面体の各菱形を中心で4分割した多面体で (patchDivisions が奇数なら2分割)、パッチの格子と同じ形なので輪郭も変わらない。core も同じ方向から葉テクスチャを引くので、同じ葉が写る |
| 2.5 → 4.5 | wood poly | 枝の細かさを2段落とす。段ごとに長さ方向の分割を半分にし、周方向の分割も3以上残る範囲で半分にする (幹 12 → 6 → 3、大枝 8 → 4 → 4、小枝 6 → 3 → 3)。粗い段の格子は細かい段の部分集合で、三角形の対角線の向きも揃えているので、消える頂点を粗い段の三角形上の同じ位置へ geomorph してから切り替える (軸・法線・AO・枝上の位置も一緒に寄せるので、風と陰影も一致する) |
| 3.6 → 5.0 | core poly | core を2段落とす。菱形の中心の頂点を対角線の中点へ寄せて菱形あたり2三角形にし、次に菱形の3本の稜線が集まる頂点 (正20面体の面の中心) を正20面体の面の重心へ寄せて、正20面体 (クラスタあたり20三角形) にする。以降はクラスタ単位のまま遠景まで描く |
| 3.8 → 4.4 | inner fade | 陰葉っぱ球の葉を縮めて消し、描画をやめる (`innerFadeStart` / `innerFadeEnd`) |
| 3.8 → 5.0 | twig fade | 小枝を細くして消す (`twigFadeStart` / `twigFadeEnd`) |
| 7.0 → 8.5 | limb fade | 大枝を細くして消す (`limbFadeStart` / `limbFadeEnd`) |

葉 (シェル・core・陰葉っぱ球) の段はクラスタごとに決めます。各クラスタの L は、樹冠の半径をそのクラスタまでの距離から見た値で、遠くの木ではすべてのクラスタがほぼ木の L にそろいます。クラスタごとの LOD の値 (反りの量、段、寄せる割合、アルファ閾値など) は、木ごとの uniform 配列でクラスタ番号から引きます。index は段ごと、その中でクラスタごとに並べてあり、同じ段で番号の続くクラスタは1回の描画にまとめ、段が混ざるときは geometry の group で分けて描きます。枝は木単位の LOD のままです。

クラスタを1つの樹冠へまとめる段 (merge) は持ちません。遠景でもクラスタの塊のまま描き、遠景用の数をさらに詰めたくなったら、インポスターに置き換える想定です。

GUI の `LOD part tint` で、shell (赤) / core (緑) / 陰葉っぱ球 (黄) を色分けして表示できます。`mode: manual` にすると、任意の L の表現を近くから確認できます。`auto dolly` はカメラを近距離から遠距離へ往復させます。

## 移植時のメモ

- 陰影・ノイズ・影は「静止位置 (LOD モーフ後・風の前)」の関数になっています。代理形状の法線は頂点に焼いて、位置と一緒に geomorph します。
- vec4 にパックした uniform のレイアウトは、各 WGSL 関数冒頭の `let` による展開と対応しています。
- クラスタのデータは float テクスチャで渡しています (row 0: 中心と影用の半径、row 1: 枝のカプセル列、row 2: 楕円体の軸、row 3: 葉テクスチャの絵の番号、row 4: 葉テクスチャの回転 (クォータニオン)、row 5: 風で曲がるときの支点と曲がりやすさ)。こぶの形は CPU 側だけで使います。
