# stylizedtree

もこもこした丸い樹冠の木 (照葉樹・ガジュマル系) を、絵画寄りの見た目で描き、遠景までシームレスに LOD するためのプロトタイプです。three.js (WebGPURenderer) で組んでいて、シェーダー本体は `src/shaders/*.wgsl` に置き、TSL の `wgslFn` で繋いでいます。

```sh
npm install
npm run dev   # WebGPU 対応ブラウザで開く
```

## 表現

- **葉のテクスチャ**: クラスタ表面全体で1枚の葉テクスチャを共有します (`leafAtlas.js` で手続き生成)。上下の半球をそれぞれ Lambert 正積方位図法の円盤として持ち、下半球は同じ円盤を鏡像で使うので、赤道で連続します (`leaf_uv.wgsl`)。UV はフラグメントごとに、クラスタ中心から見た表面の方向で求めます。楕円の葉を円盤上に一様にまばらに散らし、図法の歪みの逆をかけて描くので、球面上で形が保たれます。
- **葉のシェル**: クラスタ (楕円体に数個のこぶを足した形。`clusterShape.js`) の表面を、菱形30面体の30枚の菱形パッチで隙間なく敷き詰めます。近距離では、各パッチを中心まわりに拡大して重ね (overlap)、半径方向に深さをずらし (depth)、外側へ反らせます (flare)。テクスチャはパッチに貼り付いたまま一緒に動くので、重なったパッチ同士が同じ葉を写すことはありません。パッチの端に近いほど (パッチ内座標 x, y ∈ [0, 1] で 16x(1−x)y(1−y) が小さいほど)、またカメラに対して真横を向いたパッチほど、葉テクスチャの A (葉の中心で 1、輪郭の少し外で 0 になる距離場) に掛ける閾値を上げます (`patchFade`, `grazingFade`)。葉はそれぞれ自分の中心へ縮んで消えるので、パッチの辺で直線に切れることも、広い半透明になることもありません。
- **代理形状の法線**: 陰影はクラスタ形状の法線からフラグメントごとに計算し、パッチ自身の法線は少しだけ混ぜます。
- **縁と陰影**: 葉の縁は、ぼかしたカバレッジから作る alpha の傾斜を alpha to coverage に渡し、柔らかく残します。陰影は ramp の境界を広げ、明暗の幅と、影・AO の濃さを抑えます。GUI の `Look → style` で、以前の硬い見た目 (`crisp`) と切り替えて比べられます。
- **AO**: クラスタ同士の遮蔽を CPU でベイクし、深い位置にあるパッチほど暗くします。
- **影**: 太陽方向へのクラスタ同士の遮蔽は、球との解析的な交差で頂点ごとに計算します (`st_sunVisibility`)。地面の影も同じ関数をデカールで使い、幹の影はカプセル列で計算します。
- **その他**: 逆光の透過、空気遠近 (フォグ)、風 (幹 → クラスタ → 葉の3階層)。

## LOD

L = log2(400px / 樹冠の投影半径px) とします。距離が倍になるごとに +1 です。すべて連続な変形で繋いでいて、メッシュ構造が変わる切替は、切替前後で同じ見た目に変形し終えた時点でだけ行います。

| L (既定値) | 段 | 中身 |
|---|---|---|
| 1.4 → 3.2 | collapse | パッチの拡大・深さ・反りを 0 にして、隙間なく敷き詰めた状態へ戻す。端と真横での葉の縮小、パッチごとの色のばらつき、深さの暗さもここで消す。アルファ閾値を下げる |
| 3.2 | swap | 敷き詰め終えたパッチ群を、クラスタごとの icosphere (core) に差し替える。core も同じ方向から葉テクスチャを引くので、同じ葉が写る |
| 3.2 → 3.8 | dissolve | core の輪郭にノイズの抜きを入れ始める |
| 3.6 → 4.4 | core poly | icosphere の geomorph でクラスタ core を level 2 → 1 に落とす |
| 3.8 → 5.0 | merge | core の頂点を樹冠の距離場 (クラスタの smooth union) の外殻へ投影する。法線もクラスタ → 樹冠へ遷移させ、葉テクスチャは単色へ遷移させる。樹冠中央の補助楕円体 (filler) は、ここで中心から外殻まで膨らむ |
| 5.0 | swap | 外殻と一致した core 群を、樹冠メッシュ1枚に差し替える |
| 5.0 → 7.0 | crown poly | 樹冠メッシュを geomorph で level 2 → 0 に落とす |

GUI の `LOD part tint` で、shell (赤) / core (緑) / crown (青) を色分けして表示できます。`mode: manual` にすると、任意の L の表現を近くから確認できます。`auto dolly` はカメラを近距離から遠距離へ往復させます。

## 移植時のメモ

- 陰影・ノイズ・影は「静止位置 (LOD モーフ後・風の前)」の関数になっています。法線もフラグメントで代理形状から計算するので、メッシュの細かさに依存しません。
- vec4 にパックした uniform のレイアウトは、各 WGSL 関数冒頭の `let` による展開と対応しています。
- クラスタのデータは float テクスチャで渡しています (row 0: 中心と影用の半径、row 1: 枝のカプセル列、row 2: 楕円体の軸、row 3: こぶの基準値と鋭さ、葉テクスチャの回転とセル番号、row 4〜: こぶ1個ずつの方向と高さ)。
